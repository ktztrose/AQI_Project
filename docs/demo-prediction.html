What this page will show

Once enough historical data has been collected from the deployed sensor node, this page will display a short-horizon forecast of upcoming AQI — giving early warning of worsening air quality before it happens, rather than only reporting current conditions.

Forecasting begins after the hardware monitoring phase, once there is sufficient historical data (from both the sensor node and supplementary external datasets) to train reliable models.

Planned forecasting approach

Three different modeling approaches will be trained and compared, and the best-performing one will be used to power this page's live forecast:

ARIMA

Classical statistical baseline. Fast to train, good for stable, linear short-term trends.

Random Forest

Ensemble machine learning using lag features and time-of-day. Offers interpretability via feature importance.

LSTM

Deep learning sequence model. Best suited to capturing longer-range temporal pollution patterns, given enough data.
